# Touhou: Heartbound Wiki

The English wiki of **Touhou: Heartbound**, a fan-made block-building life sim and romance set in Gensokyo.

Read it at https://cartooncodervt.github.io/touhou-heartbound-wiki/

Touhou: Heartbound is a fan-made game based on Touhou Project. Touhou Project is the work of Team Shanghai Alice / ZUN.
